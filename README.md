# 走马灯 ZOUMADENG — 机构复刻 No.19

《燕京岁时记》走马灯:烛焰加热空气,热流推顶置 12 叶轮(安装角 45°),
纸马 4 匹绕轴环行、马影投罩——「车驰马骤,团团不休」。烛数 n ↔ 转速
ω=k·n 阶梯可验算,←/→ 调烛。B 键查看剖视图。

## 机构与验算

```
尺寸(演示值):
  纸罩   高 0.42 · 径 0.34(半透,马影投面)
  叶轮   12 叶,安装角 45°,轮径 0.20
  纸马   ×4,90° 等分,环行半径 0.13
  烛位   ×4,90° 等分

运动学(载入期断言):
  ω_target = k·n = 1.35 × n(n=烛数)
  一阶趋近,热流惯性 τ ≈ 1.6s
  1 烛 13 RPM · 2 烛 26 RPM · 4 烛 52 RPM(稳态)
```

| 键 | 阶段 | 内容 |
| --- | --- | --- |
